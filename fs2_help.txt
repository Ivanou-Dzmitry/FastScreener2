You can add graphic elements using the middle mouse button (MMB).

Available Graphic Elements:
* Arrow: Can point in different directions.
* Frame: You can choose between a fixed or free frame.
* Number: Add a number to your screenshot.
* Text (One Short Line): Add a line of text (up to 45 characters).
* Watermark: Add a watermark to your screenshot.

Use the context menu (Right Mouse Button) for options related to the Arrow, Frame, and Watermark.

Customize Graphic Elements:
Set visual options for the graphic elements and bars in the Settings (e.g., color, size, etc.).

Frame Types:
1. Free Frame: Drawn by holding the MMB and moving the mouse.
2. Fixed Frame: Added by clicking the MMB.

The bars at the top and bottom of the screenshot can mask unwanted areas. You can also set the color of these bars.

Saving and Settings:
* Your settings are saved in the fs2_settings.xml file (located in the root folder).
* The screenshot area automatically snaps to the corners of the screen.

File Handling:
* If the Save to File option is enabled and a file name is specified, the file will be overwritten each time you take a new screenshot.
* If the file name is not specified, the screenshot will be saved with a unique, automatically generated name.

DPI Settings:
* If the DPI changes while using the program (e.g., 150%, 200%), the program will restart with the original screenshot size.
* For monitors with a resolution higher than Full HD, if the screen scale is set to anything other than 100%, both the scaled and original screenshot sizes will be displayed.
* The original size will be saved to the buffer and to the file.

Screen Size and Multi-Monitor Setup:
The screenshot size cannot exceed the size of the smallest monitor in a multi-monitor setup.
