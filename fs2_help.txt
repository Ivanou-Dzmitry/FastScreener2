You can add graphics elements using middle mouse button (MMB).

Available graphic elements:
- Arrow
- Frame
- Number

Set visual options of graphics elements, and bar in the Settings (color, size etc).

The arrow can point in different directions.

The frame can be of 2 types: fixed and free.
1. Free is drawn with mouse movement with the MMB pressed
2. Adding a fixed type is done by clicking MMB.

The bar at the top and bottom allows you to mask unnecessary parts of the screenshot. You can set color of bar.

Config saved to fs2_settings.xml (root folder).

The screenshot area is snapped to the corners of the screen.

If the option to Save to File is enabled and the file name is specified, then when you take a screenshot again, the file will be overwritten.

If the DPI changes during operation, the program will restart with the first screenshot size.

For monitors with resolution higher than Full HD. If the screen scale is different from 100% (150%, 200% etc), the scaled size and the original size in which the screenshot will be taken are displayed. The original size is saved to the buffer and to the file.

If the file name is not specified, it will be saved with a unique generated name. If the file name is specified, it will be overwritten after each screenshot.
